# AIニュース風刺画端末

> 2026-10-04に母艦とPicoをPUSH版へ切り替え、Webからの送信とPicoの描画完了ACKを実機確認しました。構成と制約は[PUSH設計](docs/PUSH_DESIGN_2026-10-04.md)を参照してください。

毎時、選んだジャンルから題材を一つ見つけ、小さな白黒の絵にします。初期設定は最新AIニュースの風刺画です。Raspberry Pi 5が絵と出典を保存・公開し、Pico Wが新しい絵を電子ペーパーに表示します。ブラウザでは作品をカレンダーから振り返れます。

## できること

- CodexがWebで出典URLと文章を調べ、その内容から絵を生成します。題材11種類と作画テイスト16種類を、それぞれ設定画面で選べます。configで候補の追加・削除や説明・作画指示の編集もできます。出典や実画像を確認できないときは再試行し、失敗時は前回の絵を残します。
- 公開成功から24時間以内に使った出典URLは再採用しません。同じURLが返れば既定の最大3試行内で別の出典を探します。同じ話題でも別URLなら採用できます。
- Waveshare Pico-ePaper-2.13 V4に250×122の白黒画像を表示します。改訂版ではPico WがWi-Fi省電力モードで受信を待ち、母艦が画像をPUSHしたときだけ更新します。起動・再接続で自動取得はしません。
- 画像と出典を履歴に保存し、LAN内のブラウザで月間カレンダーと日別の作品一覧を閲覧できます。

## 必要なもの

- Raspberry Pi 5（Ubuntu）、Python 3.11以降、[Python依存](requirements.txt)のPillow。
- 認証済みのCodex CLIと、ヘッドレス実行で利用できる`gpt-6-luna`のWeb調査・画像生成機能。画像生成機能が使えなければ公開を止めます。外部有料APIへの自動切替はありません。
- MicroPythonを入れたPico W、Waveshare Pico-ePaper-2.13 V4、Wi-Fi、USB給電。確認済みのPico環境はMicroPython v1.22.1です。消費電力とバッテリー寿命は未測定です。

HTTPはLAN内専用で、追加のアプリ認証はありません。現行コードは送信元を`192.168.0.0/24`に制限するため、別のサブネットで使う場合はサーバ側の許可範囲も変更してください。WANには公開しないでください。

## はじめる

1. 母艦でこのリポジトリを用意し、Python依存とCodex CLIを使えるようにします。[config.sample](config.sample)からルートのGit管理外ファイル`config`を用意します。再試行と期限、題材・テイストの一覧はここで編集できます。Webの設定画面では各一覧から1つずつ選んで保存できます。旧configにテイスト欄がない場合は新聞風刺画が既定です。
2. 母艦でHTTPサーバとuser systemdの毎時生成timerを有効にします。最初の絵をすぐ作りたい場合は生成ジョブを一度起動します。
3. [pico/config.sample.py](pico/config.sample.py)を見本に、Git管理外の`pico/config.py`で固定IP`.172`、マスク、ゲートウェイ、DNS、送信元母艦IP、待受ポート16151を設定します。既存のGit管理外`pico/secrets.py`は読み出し・上書きせず利用します。この実機では`.172`を使用し、Wi-FiのMAC拒否は解除済みです。ルーターのDHCP配布除外または同一MACへの予約を維持してください。

各コマンド、Picoへの転送順、unit内のパスとアドレスの変更箇所は[初期導入と運用手順](docs/OPERATIONS.md)にまとめています。systemdの配布unitはこの開発環境のパスとアドレスを含むため、導入先に合わせて編集してください。

## ふだんの使い方

LAN内のブラウザで`http://<母艦のLANアドレス>:16150/`を開きます。「新しい絵を生成」を押すと、毎時のタイマーを待たずに現在の題材とテイストで新しい絵を作ります。画面に進行・完了・失敗を表示し、成功後は最新画像とカレンダーを更新します。連打や毎時処理中の重複起動は受け付けません。

「題材とテイストを選ぶ」で、それぞれの名前と説明を確認して保存できます。候補は`config`の`[[news.topics]]`と`[[styles.items]]`にあり、IDを保ったまま名前・指示文・並び順を編集できます。設定画面を開くたびに実configを読み直すため、追加・削除も次回表示に反映されます。選択中のIDを削除した場合は勝手に別候補を選ばず、選び直すまで生成を始めません。保存は次の手動生成と毎時生成から反映され、進行中のジョブの題材と画風は変わりません。毎時の生成結果と出典はギャラリーに残り、新しい画像ができなかった回は前回の表示を維持します。生成・公開後は自動でPicoへPUSHし、各作品の「PICOに表示」で一時的に選んだ絵を送れます。送信失敗でも作品は保存され、再接続だけでは自動再送しません。
