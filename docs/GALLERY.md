# ブラウザアーカイブ追加仕様

正式設計書v0.1への追加要件です。正式原本は変更しません。

## ポート決定

正式設計書の母艦HTTP `8001` は初期案です。ユーザー決定により既定ポートを **16150** に変更しました。PicoのPULLとブラウザ閲覧は同じ母艦 `http://192.168.0.120:16150` を使います。8080はNginx用に確保されているため使用しません。母艦の `AI_NEWS_PORT` と Pico の `pico/config.py` で変更可能です。変更時は両側を一致させます。

## 画面とデータ

- `/gallery/`: PC/スマホ対応の月間カレンダー。前月/翌月へ移動でき、各日に代表サムネイルと件数を表示します。
- 日付を選ぶと、その日の全画像を生成時刻順に表示します。見出し、JST生成日時、出典URLを示します。出典未登録はその旨を表示します。
- 最終PNGを再利用し、ブラウザでは `image-rendering: pixelated` で拡大します。元画像や履歴は変更・自動削除しません。
- 日付は保存された `created_at` UTCをJSTへ変換して分類します。空の日と月も表示できます。

## 安全性

ユーザー指定により、このアプリはLAN内専用・追加認証キーなしです。`192.168.0.120`へのbindと `192.168.0.0/24` の送信元制限を設け、閲覧APIは保存済みデータの読み取り専用です。LAN内の端末なら閲覧でき、HTTPの内容や非認証SHA-256は盗聴・改ざんに対する真正性を保証しません。WAN公開は行いません。OS/firewall/既存サービスの認証設定は変更しません。

## 確認項目

単体テストでJST日付境界、複数画像、空日/月、出典欠落、LAN送信元制限、画像配信を確認しました。ループバックの一時サーバとCodex内蔵ブラウザでPC幅・390pxのスマホ幅、日付クリック、空月、pixelated拡大を視覚確認しました。実際のニュース題材で生成した風刺画も検証用・本番未公開として追加し、ブラウザで出典リンクと画像を確認しました。実機表示は未確認です。
