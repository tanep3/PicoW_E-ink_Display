# ブラウザアーカイブ追加仕様

実装前の設計書v0.1への追加機能です。現在の接続・運用仕様は[実装仕様](IMPLEMENTED_SPEC.md)を参照してください。

## ポート決定

正式設計書の母艦HTTP `8001` は初期案です。ユーザー決定により既定ポートを **16150** に変更しました。ブラウザは母艦 `http://192.168.0.120:16150` を開きます。Picoの現行版は母艦から`192.168.0.172:16151`へのPUSHを受けます。8080はNginx用に確保されているため使用しません。母艦の `AI_NEWS_PORT` と Pico の `pico/config.py` で変更可能です。

## 画面とデータ

- `/` と `/gallery/`: 冒頭では日本時間の日付から絵を探せることを案内し、最新の本番画像、「新しい絵を生成」ボタン、設定画面への入口、下記の月間カレンダーを表示します。手動生成の進行・完了・失敗は画面内に表示し、完成後は最新画像とカレンダーを更新します。
- `/settings/`: `config`に登録された題材と作画テイストを、それぞれ独立して選び保存します。短い題名と開閉できる指示文を表示し、保存済みの選択と未保存の変更を区別します。候補の追加・削除・並び替え・指示文変更は画面を開くたびに反映し、選択中IDが消えたら再選択を促します。
- `/gallery/`: PC/スマホ対応の月間カレンダー。前月/翌月へ移動でき、各日に代表サムネイルと件数を表示します。
- 日付を選ぶと、その日の全画像を生成時刻順に表示します。見出し、JST生成日時、出典URLを示します。出典未登録はその旨を表示します。
- 最終PNGを再利用し、ブラウザでは `image-rendering: pixelated` で拡大します。元画像や履歴は変更・自動削除しません。
- 日付は保存された `created_at` UTCをJSTへ変換して分類します。空の日と月も表示できます。

## 安全性

ユーザー指定により、このアプリはLAN内専用・追加認証キーなしです。`192.168.0.120`へのbindと `192.168.0.0/24` の送信元制限を設け、閲覧APIは保存済みデータの読み取り専用です。LAN内の端末なら閲覧でき、HTTPの内容や非認証SHA-256は盗聴・改ざんに対する真正性を保証しません。WAN公開は行いません。OS/firewall/既存サービスの認証設定は変更しません。

## 確認項目

単体テストでJST日付境界、複数画像、空日/月、出典欠落、LAN送信元制限、画像配信を確認しました。ループバックの一時サーバとCodex内蔵ブラウザでPC幅・390pxのスマホ幅、日付クリック、空月、pixelated拡大を視覚確認しました。実ニュースを題材にした風刺画を検証用として追加した後、承認を受けて同じ作品を本番latestにも公開しました。検証用コピーはギャラリー上で区別されます。Picoでの本番画像表示はユーザーが確認しました。

## PUSH改訂（稼働版）

日別一覧の各作品に「PICOに表示」ボタンを置きます。保存済み作品をその場限りPicoへ送信し、母艦のlatestと公開履歴は変更しません。生成結果とPUSH結果は別の状態欄に表示します。接続・timeout・データ検証・描画・結果不明・公開後の送信登録失敗の区分を短い日本語で知らせます。詳細は[PUSH設計](PUSH_DESIGN_2026-10-04.md)を参照してください。
